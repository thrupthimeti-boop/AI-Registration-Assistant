# AI Registration Assistant

An AI-powered registration assistant that helps students with course registration, eligibility checks, and registration guidance.

## Features

- Greeting and introduction
- User information collection
- Intent recognition
- Eligibility checking
- Course information
- Registration guidance
- Simple conversational chatbot

## Technologies Used

- Python
- NLP
- NLTK
- Scikit-learn
- Machine Learning
